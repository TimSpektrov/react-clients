Запуск проекта осуществляется через npm i && npm run dev



В данной реализации хранение данных организованно через localStorage, в будущем планирую перенести в базу данных и добавить бэк на express

Возможности приложения:
- ролевой доступ:
    - Возможно залогиниться под пользователем username:admin, password: admin
    - создать своего пользователя
    - для выхода из системы нужно нажать на аватар под ним появится кнопка "выйти"
- возможно создание нового клиента, редактирование и удаление:
    - после входа в приложение на главной странице отображается таблица с клиентами, в хэдере есть кнопка создать нового, при клике переходит на страницу создания 
    - при клике на любую строку в таблице переходим на страницу подробной информации о клиенте
    - на странице подробной информации внизу есть 2 кнопки удалить и отредактировать данные
